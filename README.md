# 🐍 The Snake

Мой первый проект на Python !

Небольшая игра «Змейка», написанная на Python с использованием Pygame.

## 🚀 Запуск

```bash
git clone https://github.com/click002/the_snake.git
cd the_snake
pip install -r requirements.txt
python the_snake.py
```
